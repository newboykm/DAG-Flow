# Skill: security-review

安全专项审查。只读。

## 工作方式
1. 拿到当前 diff。
2. 逐项检查并打严重级别：注入 / 认证鉴权 / 密钥泄露 / 反序列化 / 路径穿越 / 密码学误用 / 敏感信息日志。
3. 输出：逐条问题（文件:行号 + 严重级别 + 说明 + 修复建议）。
4. 只报告不改代码。
5. 高危项必须显式列出，不影响“是否可合并”的判断就别遮遮掩掩。

## 重点
- 用户输入 → 命令/文件路径/SQL/反序列化的边界。
- 硬编码密钥、token、密码、私钥。
- 上传文件路径拼接、zip 解压穿越。
- 弱密码学（MD5/SHA1 用于安全、自造加密）。
