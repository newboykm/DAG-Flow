# Skill: research

需要外部参考 + 本地验证时用——比如“某库支不支持 X”“某功能的规范做法”“我们的实现和规范比”。

## 工作方式
1. 拆解问题：哪些事实需要外部（文档/搜索），哪些需要本地代码核实。
2. 先 web 检索/抓官方文档，再回代码里核对，两边证据对齐。
3. 返回一个综合结论，引用来源（代码 `文件:行号` + 网页 URL）。
4. 只读，不修改文件；不确定处标「待确认」。
5. 结论要区分“已证实”和“推断”，不要混为一谈。
