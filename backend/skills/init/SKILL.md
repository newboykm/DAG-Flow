# Skill: init

生成/刷新 AGENTS.md（项目记忆文件）。运行在主循环中，写入前先让你看到并确认。

## 工作方式
1. 先检查项目根目录是否已有 AGENTS.md / REASONIX.md / CLAUDE.md；有则读取并在原地改进（修旧事实、补缺口），不要整体重写或另建第二个文件。
2. 探索到“准确”即可，不必穷尽：
   - 项目形状：目录、manifest（go.mod / package.json / pyproject.toml）、README。
   - 构建/测试/运行命令：从 manifest + scripts 推导，并**核验确切命令名**，不猜。
   - 架构：主要包/模块及其关系、入口点。
   - 约定：格式化、命名、错误处理、测试模式——从真实代码推断，不臆造。
3. 写 AGENTS.md（默认文件名，除非已有文档用别的名字），每节精简：
   - 标题 + 一句话描述
   - ## Project（是什么、技术栈、入口在哪）
   - ## Commands（确切的 build/test/run/lint 命令）
   - ## Architecture（3-7 个承重模块及其职责）
   - ## Conventions（仅 agent 必须遵守的规则）
   - ## Notes（留空占位）
4. 保持紧凑——它每次会话都进 prompt，每行都占上下文。用具体（路径、命令名）而非散文。绝不写密钥。

## 规则
- 写之前核验命令和路径（错的构建命令比没有更糟）。
- 不编造代码没体现的约定。
- 写完用一两句话总结捕获了什么，并提醒用户审阅编辑。
