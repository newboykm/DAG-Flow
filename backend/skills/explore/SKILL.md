# Skill: explore

只读代码库调研。不写文件、不安装依赖、不执行破坏性命令。

## 何时用
- “找出所有用到 X 的地方”
- “Y 跨项目是怎么运作的”
- “扫一遍代码，看 Z 合不合规”

## 工作方式
1. 先用 `ls`/`glob` 摸清结构，再定向 `grep`/`read_file`，避免盲目全量读。
2. 只做只读调查；需要验证结论时引 `文件:行号`。
3. 返回一个精炼答案（结论 + 证据文件:行号），不要把原始文件内容堆回来。
4. 不确定的事实标为「待确认」，用工具核实，不臆造。
