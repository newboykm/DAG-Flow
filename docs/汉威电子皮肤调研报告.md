## 二、这款"电子皮肤 / 皮肤衣"是什么

### 2.1 一句话概述
一种**电容式柔性敏感织物**做成的、可穿在机器人身上的"全身电子皮肤"，相当于给机器人装上**覆盖全身的触觉"肌肤"**——能感知触碰、按压、轻拍等，灵敏度接近真人皮肤。

### 2.2 技术原理与参数（公开报道）
| 项目 | 内容 |
|------|------|
| 技术路线 | **电容式柔性敏感织物**为基底，**双层织物结构**把大面积压力阵列传感器与服装集成 |
| 灵敏度 | **0.1N 级**（能感知羽毛轻拂级/极轻的压力） |
| 响应速度 | **毫秒级**（毫秒级响应，动态适应环境与曲面） |
| 形态 | 可穿戴"外衣"，**穿脱方便、活动自然**，自适应各类曲面 |
| 外观 | 银色科技感面料 + 哑光拼接、流线型立体剪裁 |
| 交互能力 | 支持**十余种智能交互动作**（握手触碰、轻拍接触、触摸肩部转头等） |
| 应用场景 | 协作机器人防护（人机协作防误伤）、家庭服务机器人交互（轻柔照料老人儿童）等 |

### 2.3 它解决什么痛点
传统机器人"只会执行指令、缺乏感知"。电子皮肤为机器人补上**触觉**这一最关键的多模态感知短板，让机器人能：
- 感知自身被触碰/按压的力度与位置；
- 在执行精细动作（如抓取易碎物）时实时调节力度、保证精准与安全；
- 在人机协作中感知异物触碰，从源头避免误伤。

## 三、相关背景：为什么是河南、汉威、以及"中豫"实验室

### 3.1 汉威科技
- 创立于 1998 年，**深交所创业板首批上市公司**（代码 300007）。
- 国内传感器龙头：气体传感器国内市场占有率约 70%（第一）、产销量全球前三。
- 已掌握柔性压阻、柔性压电、柔性电容、柔性汗液**四大核心柔性技术**，具备大面积阵列设计、敏感材料/导电墨水合成、大面积印刷电子批量制造能力，拥有数条年产千万支柔性传感器的产线。
- 具身智能感知产品矩阵：**触觉、嗅觉、平衡、力控、视觉**五大类（柔性触觉传感器、AI-NOSE 电子鼻、九轴惯性传感器芯片 HAU925、弹性动作捕捉服、六维力传感器、数据手套、非制冷红外热成像模组等）。
- 技术源点：柔性触觉技术来自子公司**苏州能斯达**（2013 年启动产业化，早期用于医疗/睡眠/可穿戴，近年切入机器人）。

### 3.2 中豫具身智能实验室
- 由**河南省科学院牵头**建设，对标国家级科研平台，聚焦**具身智能、人形机器人**等领域攻关。
- 河南官方媒体（河南日报《中原观察》等）将它与汉威电子皮肤**并列**作为河南机器人产业的关键布局：
  > "省科学院牵头建设中豫具身智能实验室……汉威科技研发柔性传感器，为人形机器人披上'电子皮肤'……"
- 关于它与**这款皮肤衣的共同研发关系**，见"核心结论"中的提示——建议进一步核实。

### 3.3 卓益得机器人
- 汉威发布这款全身电子皮肤的**联合方**，公开报道中明确为"汉威科技 × 卓益得机器人"。

## 五、产业与商业化预期（来源：2026 WRC 董事长任红军访谈）

- 电子皮肤**已进入"批量规模产业化拐点"**：已落地 30+ 客户，部分客户已下小批量订单。
- 预期：**未来两年**电子皮肤从小批量转向规模化供应；**嗅觉、力控**类产品 2—3 年形成业务规模，大规模利润释放约需 2—3 年后。
- 行业仍处早期：技术路线未收敛，**感知实际落地最缺的是"系统设计 + 端侧算法"的复合型方案设计人才**。
